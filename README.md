# knotted

기획과 시안을 한 제안서로 엮어 확정하는 Knot 팀 도구의 프로토타입입니다. 팀원이 채팅으로 기능을 정하면 요구사항과 시안이 함께 쌓이고, 컨펌 담당은 그 제안서 한 장을 보고 확정, 보류, 반려를 고릅니다.

지금은 Figma 시안대로 눌러 보며 피드백을 받기 위한 버전이라 배포하지 않고 로컬에서만 띄웁니다.

## 실행

```bash
pnpm install
pnpm dev
```

브라우저에서 http://localhost:5180 을 엽니다.

코드 보기의 '에디터에서 열기'를 쓰려면 `.env.local`에 Knot 저장소 위치를 적습니다.

```bash
VITE_KNOT_REPO=/Knot/저장소/절대/경로
```

## 눌러 볼 순서

1. 제안함에서 로그아웃 제안을 엽니다. 위쪽의 '유월로 보는 중'을 눌러 팀원 A와 유월을 바꿔 가며 봅니다.
2. 유월로 보면 반려, 보류, 확정 버튼이 있습니다. 확정하면 오른쪽에 팀원의 에이전트가 노션, QA 시트, 디자인, 이슈에 하나씩 반영하는 목록이 뜹니다.
3. 캔버스에서 요소에 마우스를 올리면 디자인 시스템 이름이 뜨고, 누르면 툴바가 뜹니다. 댓글, AI에게 요청, 코드, 링크 복사, 글자 고치기를 써 봅니다.
4. C를 누르면 요소를 누르거나 영역을 끌어 댓글이나 수정 요청을 남깁니다. 남긴 것은 핀과 오른쪽 댓글 탭에 보입니다.
5. 수정 요청은 잠시 뒤 고침 상태가 되고, 바꾸기 전과 바꾼 뒤를 비교하거나 되돌릴 수 있습니다. '로그아웃 글자를 조금 더 연하게 해 줘'처럼 쓰면 화면에도 반영됩니다.
6. 흐름 보기에서 프로필 사진을 눌러 실제 앱처럼 로그아웃해 봅니다. 아래 '상황 바꾸기'로 녹음 중, 실패 상황을 고릅니다.
7. 제안서에서 '지금 화면과 비교'를 누르면 경계선을 끌어 지금 화면과 시안을 겹쳐 봅니다.
8. 위쪽 디자인 메뉴에서 디자인 시스템, 정책, 유저 플로우를 봅니다. 확정이 끝나면 점선이 실선으로 바뀝니다.
9. 처음부터 다시 보려면 '보는 중' 메뉴의 '데모 처음부터'를 누릅니다. 새 제안을 누르면 채팅으로 로그아웃 기능을 처음부터 기획합니다.

## 지금은 흉내만 내는 것

- 에이전트: 실제 Claude Code와 연결하지 않았습니다. 기획 대화와 수정 요청은 정해진 순서로 답합니다.
- 시안 화면: Knot 코드를 불러오지 않고, Figma의 로그아웃 화면을 보고 이 저장소의 `src/knot-app`에 다시 그렸습니다.
- 저장: 브라우저 localStorage에 둡니다. 실제 버전은 서버와 DB 없이 Knot 저장소의 `.knotted/` md 파일에 둡니다.

## 폴더

```
src/
  knot-app/   시안 안에 들어가는 Knot 화면(데모)
  features/
    canvas/   캔버스, 요소 툴바, 핀, 댓글 작성
    panels/   대화, 댓글, 살펴보기, 규칙 패널
  pages/      제안함, 제안서, 캔버스, 흐름 보기, 화면 비교, 디자인 페이지
  data/       로그아웃 제안, 요구사항, 컴포넌트 정보
  store/      데모 상태
design/       구현 기준으로 쓴 Figma 시안 캡처
```
